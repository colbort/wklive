# OPT-P2-004 公司行动仓库级验收记录

## 1. 结论

截至 2026-08-02，拆分/反向拆分的单一现金后继 V1 已完成仓库级 MySQL、Redis 和真实 Asset gRPC
验收。5001 个持仓按每批 100 条迁移，在第 101 条注入未完成保证金后失败隔离；解除阻塞后用新的
任务实例从数据库游标继续，最终无漏项、重复项或部分持仓。两笔真实保证金冻结在迁移前后均为
100 USDT，只存在最初 2 条 Asset 流水，Option 不生成释放或重冻结指令。

本结论不等于允许生产开放。生产/预生产仍须完成容器编排级强杀、多实例调度、权限与通知演练，
并由业务、法务、清算和风控批准目标市场规则、公告来源、税费与零碎权益政策。合并、分叉、空投、
篮子、实物交割物变化和未知下架规则仍只允许 `MANUAL_ONLY`。

## 2. 本轮发现并修复的问题

1. 公司行动复核门禁没有包含 `EXPIRING` 订单，可能在到期释放资金期间批准迁移。复核现在对
   `FUNDING/PENDING/PART_FILLED/CANCELING/EXPIRING` 全部 fail closed。
2. 执行门禁错误查询不存在的 `t_option_asset_instruction.contract_id`，真实 MySQL 会在迁移前失败。
   现在通过订单、成交、持仓、margin lot、强平和实物交割单元的租户内关联追溯合约，并有模型
   回归测试锁定 SQL 结构。
3. 风险扫描会对 5001 个同合约持仓重复查询活动迁移并拼接相同错误。现在每个租户/合约只查询
   一次，每个钱包/合约只记录一次迁移错误，仍把受影响钱包置为
   `RESTRICTED/last_calc_time=0`。

- 公司行动：事件 `COMPLETED`，映射 `COMPLETED`，`total/completed/failed=5001/5001/0`，

- 资产：钱包 `total/available/frozen=200/100/100`；冻结记录 2、剩余冻结 100、Asset 流水 2，
  公司行动用户的 Option 资产指令 0。

  5001 次重复错误和多 MB 日志。
